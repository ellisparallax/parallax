PROJECT PARALLAX
PRIMARY DIRECTIVE

Map the global UAP record — every verified incident, every credible sighting — on one globe, with the evidence attached. Filter the noise. Follow the signal. Let the data speak for itself.

WHY TRUST THIS DATA
PROVENANCE ON EVERYTHINGEvery case carries a class rating (A / B / H), named sources, and links to the primary record where one exists.
WE SHOW THE MISSESThe Sensor Differential on each case records what detected the object — and what failed, was jammed, or disappeared into custody. Negative evidence is evidence.
BIAS DISCLOSEDRecords skew toward Western, English-language open sources. Absence of data is not absence of events — the map says so itself.
NOTHING QUIETLY DELETEDContested material is labeled contested. Debunked material stays on file as calibration. Unknown means unknown — never more, never less.
